# Prime Trust Financial & Investment Company

A modern, institutional-grade, fully responsive financial wealth management web application built with **Next.js 15**, **React 19**, and **Tailwind CSS**.

---

## 🌟 Overview & Key Features

- **Responsive Multi-Device Layout:** Flawless rendering across Mobile (< 768px), Tablet (768px - 1024px), and Desktop (> 1024px) displays.
- **Glassmorphic Navigation:** Centered navigation bar (`Home`, `About us`, `Investment`, `Contact us`) with slide-out drawer on mobile and gold shimmer call-to-actions.
- **Interactive Return Calculator:** Real-time yield simulation with INR slider, preset allocation buttons, and institutional monthly payout breakdowns.
- **Micro-Interactions & Motion:**
  - Card hover elevations (`.hover-card-effect`)
  - Gleam shimmer effect on action buttons (`.btn-shimmer`)
  - Top scroll progress bar indicator & floating back-to-top button
  - Link hover gold underlines (`.link-gold-hover`)
- **Modern Institutional Footer:** Dark obsidian aesthetic (`#0a0e17`) with interactive intelligence newsletter subscription, click-to-copy verified email desk, and regulatory compliance notices.

---

## 🚀 Live Pages & Routes

- `/` – **Home** (Institutional hero, verified track record, interactive return calculator, transaction ledger, FAQ)
- `/about` & `/about-us` – **About Us** (Executive overview, 3 foundational pillars, corporate values, custody governance)
- `/investment` & `/investment-plans` – **Investment Plans** (Growth Plan showcase, 4-step onboarding workflow, collateral model, withdrawal policies)
- `/contact` & `/contact-us` – **Contact Us** (Direct inquiry form, verified advisory email desk, fraud warning banner)

## 🛠️ Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Raylancer06/primetrust.git
   cd primetrust
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Production Build:**
   ```bash
   npm run build
   npm run start
   ```

---

## 🚢 Deploy to Vercel

1. Import the repository `Raylancer06/primetrust` on [vercel.com/new](https://vercel.com/new).
2. Framework Preset will be automatically detected as **Next.js**.
3. Click **Deploy**.
